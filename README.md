# Bun Run
A small arcade game for the original Game Boy, written entirely in assembly with the [RGBDS](https://rgbds.gbdev.io/) toolchain.

<img width="640" height="576" alt="image" src="https://github.com/user-attachments/assets/62aa6532-28d5-49a9-83fc-f59f086e431a" />

## Why
It's been too long since I coded something just for fun. Between life getting busy and AI, I haven't suffered enough. So I remade the first game I ever made(originally in Unity) for the Game Boy with as little AI coding as I could.

## How to play
| Button | Action |
| --- | --- |
| D-pad left/right | Move the bunny |
| Start | Start a game from the title screen, or return to the title screen after a game over |

### Scoring
- **+1 point** for every second you survive
- **+10 points** for every coin you collect
- Your **high score** is saved to battery-backed cartridge RAM, so it's still there after you turn the game off
